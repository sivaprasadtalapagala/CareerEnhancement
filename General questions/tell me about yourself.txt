* How You Used TokenEx in Your Angular Application
For example, when a user enters their debit card details to buy a policy, the card number is captured through TokenEx’s iFrame.
Angular sends this to TokenEx, TokenEx returns a single-use token, and only that token goes to our backend.
Our backend then sends the token to the payment gateway, which maps it back to the actual card number securely.
This ensures full PCI compliance and reduces security risk.

----------------,Pipe with Arguments
import { Pipe, PipeTransform } from '@angular/core';

@Pipe({
  name: 'truncate'
})
export class TruncatePipe implements PipeTransform {

  transform(value: string, limit: number = 20): string {
    if (!value) return '';
    return value.length > limit ? value.substring(0, limit) + '...' : value;
  }

}

-------------------,Pipe with Multiple Arguments
@Pipe({ name: 'greet' })
export class GreetPipe implements PipeTransform {
  transform(name: string, greeting: string = 'Hello'): string {
    return `${greeting}, ${name}!`;
  }
}

-------------------

All pipes are pure pipes,until you add pure: false

@Pipe({
  name: 'myPipe',
  pure: false
})

If you have an array, and you push new items into it,
a pure pipe won’t detect it (because the reference didn’t change).
An impure pipe will detect it and re-run automatically.

----service--
export class DataService {
  // 🔹 1. Subject - does NOT store old values
  subjectData$ = new Subject<string>();

  // 🔹 2. BehaviorSubject - stores the latest value
  behaviorData$ = new BehaviorSubject<string>('Initial Value');

  // 🔹 3. ReplaySubject - stores multiple previous values (e.g., last 2)
  replayData$ = new ReplaySubject<string>(2);

  // Methods to send data
  sendViaSubject(value: string) {
    this.subjectData$.next(value);
  }

  sendViaBehavior(value: string) {
    this.behaviorData$.next(value);
  }

  sendViaReplay(value: string) {
    this.replayData$.next(value);
  }
}



------componet

@Component({
  selector: 'app-root',
  template: `
    <h3>Subject: {{ subjectValue }}</h3>
    <h3>BehaviorSubject: {{ behaviorValue }}</h3>
    <h3>ReplaySubject: {{ replayValue }}</h3>

    <button (click)="sendData()">Send New Data</button>
  `
})
export class AppComponent implements OnInit {
  subjectValue = '';
  behaviorValue = '';
  replayValue = '';

  constructor(private dataService: DataService) {}

  ngOnInit() {
    // 🔹 Subscribe to Subject
    this.dataService.subjectData$.subscribe(val => {
      this.subjectValue = val;
    });

    // 🔹 Subscribe to BehaviorSubject
    this.dataService.behaviorData$.subscribe(val => {
      this.behaviorValue = val;
    });

    // 🔹 Subscribe to ReplaySubject
    this.dataService.replayData$.subscribe(val => {
      this.replayValue = val;
    });
  }

  sendData() {
    const random = Math.floor(Math.random() * 100);
    this.dataService.sendViaSubject('Subject ' + random);
    this.dataService.sendViaBehavior('Behavior ' + random);
    this.dataService.sendViaReplay('Replay ' + random);
  }
}


Type	Behavior	Example Output
Subject	Sends only new data after you subscribe	You’ll miss old messages
BehaviorSubject	Sends the last value immediately + new ones	You get the most recent state
ReplaySubject	Sends a few past values (based on buffer size)	Great for “chat history” style

export class AppComponent {
  constructor(private userService: UserService) {
    const searchBox = document.getElementById('search') as HTMLInputElement;

    fromEvent(searchBox, 'input').pipe(
      map((event: any) => event.target.value),
      debounceTime(500), // wait 0.5s after typing
      switchMap(id => this.userService.getUser(id))
    ).subscribe(user => console.log('Latest user:', user));
  }
}
